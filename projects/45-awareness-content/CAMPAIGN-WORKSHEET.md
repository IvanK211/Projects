# Authorized awareness campaign worksheet

Define written approval, audience category, learning objective, approved sender identity, timing, support contact, data minimization, success metric, retention and debrief before delivery. Put actual recipient lists and sender configuration in private systems, not this worksheet.

The bundled landing page is a static education page. It has no credential form, script, tracking request or external asset. Do not transform it into a credential-harvesting page. A simulation should never solicit real passwords, recovery codes, payment details or access tokens.

Preflight a small authorized test group. Validate safe links, accessibility, reporting route and opt-out/exception handling. Measure recipient exposures consistently, exclude undelivered messages from the delivered denominator, de-duplicate recipient events within each campaign and keep reports distinct from failures.

Debrief with the intended learning point and a verified route for reporting suspicious messages. Avoid public rankings of employees or small groups. Use invented campaign results for public portfolio screenshots and demonstrations.
