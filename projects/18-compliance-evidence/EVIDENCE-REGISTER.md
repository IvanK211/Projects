# Control-evidence register template

| Field | Purpose |
|---|---|
| Control reference | Relevant framework/policy reference; verify applicability privately |
| Claim | Narrow statement of what the control is intended to do |
| Scope and exclusions | Systems and populations covered; live inventory stays private |
| Procedure owner role | Accountability without embedding a person's identity in this public template |
| Evidence type | Configuration review, test, approval, alert response or sampled activity |
| Collection window | Approved private audit period |
| Test method | Reproducible procedure and expected result |
| Result | Pass, fail, partial or not tested; do not collapse unknown into pass |
| Limitations | Sampling, access, retention and tooling limitations |
| Exception and review | Approval reference, expiry and next review, held privately |
| Storage and retention | Access-controlled location and disposal rule, defined privately |

Do not paste evidence exports into a public register. A product purchase or screenshot of a dashboard does not alone establish control effectiveness. This worksheet is not a certification statement or legal opinion.
